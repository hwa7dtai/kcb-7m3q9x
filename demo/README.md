# 课程表工具 · 前端 Demo

一个**纯前端**的课程表产品原型：不接后端、不写服务端接口，全部数据来自内置模拟数据（mock data），增删改查只在浏览器内存中生效。

视觉为**深色电影感**风格（青色高亮 + 玻璃拟态 + 氛围粒子），动效参考了一段个人主页 Hero 视频（见下文「动效设计」）。

## 运行方式

两种方式任选：

1. **直接打开**：双击 `index.html` 即可运行（无需构建、无需安装依赖）。
2. **本地服务**（推荐，便于手机同局域网访问 / 安装 PWA）：

   ```bash
   cd demo
   python -m http.server 8080
   # 浏览器打开 http://localhost:8080
   ```

> 数据保存在内存中，刷新页面即恢复到初始 mock 数据，不会写入任何持久化存储。

## PWA（可安装 / 离线可用）

Demo 自带完整 PWA 基建，手机浏览器打开后可通过「添加到主屏幕」安装为独立 App：

- `manifest.webmanifest`：应用名、主题色（`#07090d`）、独立窗口（standalone）、图标清单
- `icons/`：192 / 512 / maskable 三档 Android 图标 + 180 apple-touch-icon
- `sw.js`：应用外壳缓存优先，离线可继续查看课表；导航请求统一回退 `index.html`
- 移动端适配：`viewport-fit=cover` + 安全区 inset（刘海/小白条）、`pointer: coarse` 触控目标放大
  （≥36px）、玻璃效果降档（更小模糊半径省 GPU）、触屏按压点亮玻璃高光

> 注意：**安装 PWA 需要 http(s) 环境**（localhost 或局域网 IP 均可，`file://` 双击打开只能查看不能安装）。
> iOS 需用 Safari「添加到主屏幕」；Android Chrome 地址栏会有安装提示。

## 核心页面

| 页面 | 内容 |
|---|---|
| 周课表 | 7 天 × 12 节次网格、最左侧为每节课上下课时间轴、今天列高亮、当前节次脉冲标记、上午/下午/晚间分段线、周次切换、点击课程查看 |
| 课程管理 | 搜索、课程列表、查看详情、编辑、删除、新增、从教务系统导入，以及数据管理（重置 / 清空） |

## 演示路径（可完整走通）

1. 打开后进入**本周课表**（按当前日期自动定位教学周，加载时显示骨架屏）
2. 切换**上一周 / 下一周**，或点「回到本周」；翻到**第 17、18 周**时展示**空数据状态**
3. 点击任意课程块 → 弹出**课程详情**（教师、地点、学分、周次规则、具体上课周次、备注）
4. 切换到**课程管理**：搜索「王」「信息楼」等关键词实时过滤；清空搜索后恢复
5. 点「详情 / 编辑 / 删除」完成**查、改、删**；删除带二次确认
6. 点「新增课程」→ 填写表单 → 保存后课表与列表**立即同步更新**
7. **故意填一个冲突时间**（如周一第 1-2 节、第 1-16 周），保存时会提示「与已有课程时间冲突」
8. 点「**从教务系统导入**」→ 填写学号密码（演示模式任意填写）→ 读取到 10 门模拟课程，其中 5 门与现有课表**冲突并置灰**，勾选其余 5 门导入，课表与列表同步更新
9. 在**课程管理**工具栏右侧点「清空课程」→ 展示**整体空数据状态**；再点「重置数据」恢复

## 覆盖的状态

- 加载中：骨架屏
- 列表：有数据 / 搜索无结果 / 完全无数据
- 详情：正常详情
- 空数据：某周无排课、搜索无匹配、清空后的整体空状态
- 反馈：新增、更新、删除、冲突、校验失败均有 Toast 提示

## 模拟数据设计

数据刻意贴近真实排课场景，10 门课程覆盖了：

- 连堂课（跨 2 节）
- 连堂四节的实验课（第 5-8 节，双周）
- 单周 / 双周排课
- 晚间课程（第 9-10 节）
- 短周期课程（前 8 周结课）
- 同一时段多门课（靠不同周次规则区分）
- 空周次（第 17、18 周无课，用于展示空状态）

数据模型：

```
Course {
  id, name, teacher, location, credit, category, color, note,
  dayOfWeek: 1-7,
  startPeriod, endPeriod,            // 1-12 节
  weekRule: { from, to, pattern },   // pattern: all | odd | even
  source?: 'jwxt'                    // 来自教务系统导入的课程带此标记
}

Semester { id, name, startDate, totalWeeks, currentWeek, periodTimes }
```

`periodTimes` 为 12 节课各自的上下课时间（如第 1 节 08:00-08:45），
用于课表左侧时间列、课程列表与详情中的上课时间展示。

## 数据层的替换方式（重点）

所有数据访问都集中在 `js/store.js`，对外暴露的方法如下，**全部返回 Promise**：

```js
getSemester()                 // 学期信息（含当前周、各节次上下课时间）
getWeekDates(week)            // 某一周每天的日期
listCourses({ keyword })      // 课程列表，支持关键词过滤
getCourse(id)                 // 课程详情
createCourse(payload)         // 新增
updateCourse(id, payload)     // 更新
deleteCourse(id)              // 删除
getSchedule(week)             // 某一周的课表
fetchFromJwxt({ studentId, password })   // 模拟连接教务系统读取课表
importCourses(list)           // 批量导入，逐门校验与冲突检测，返回导入/跳过明细
```

因此 UI 层已按「异步接口」的方式编写，**接入真实后端时只需替换 `store.js` 内部实现，UI 层无需改动**。例如：

```js
// 替换前（Mock）
listCourses: function (params) {
  var keyword = String(params.keyword || '').trim().toLowerCase();
  var list = db.courses.filter(/* ... */);
  return delay(list.map(decorate), 260);
}

// 替换后（真实接口）
listCourses: function (params) {
  return fetch('/api/courses?keyword=' + encodeURIComponent(params.keyword || ''))
    .then(function (res) { return res.json(); });
}
```

只要保持方法名与返回结构不变，`js/app.js` 一行都不用改。

`resetDemo()` 与 `clearCourses()` 仅为演示空数据状态而存在，接入真实接口后可删除。

## 动效设计

整体动效语言来自一段个人主页 Hero 视频，提取了四个特征并适配到工具型页面：

| 视频中的特征 | 在本 Demo 的实现 |
|---|---|
| 标题淡入 + 放大 + 辉光 | 首屏分层入场（顶栏 → 周次条 → 课表依次浮起）；周次标题渐变文字 + 「本周」徽标辉光 |
| CTA 细边框描边绘制 + 呼吸光晕 | 「从教务系统导入」按钮：四边框顺序描边（先上下边左→右，再左右边上→下，约 1s），描边完成后一道高光每 4.6s 周期扫过，辉光持续呼吸 |
| 环境粒子飘落 | 全屏 canvas 粒子层（`js/particles.js`）：青色/白色光点缓慢下落并正弦摆动、透明度闪烁，密度随屏宽调整 |
| 电影感氛围背景 | 双层雾气光斑缓慢漂移、暗角、胶片颗粒噪点；弹窗为毛玻璃 + 弹簧缩放入场 |

其他交互动效：课程色块错峰入场（每门延迟 45ms）、悬停上浮 + 辉光、周次切换整表重绘、导航分段指示器滑动、Toast 下滑。

### 苹果液态玻璃（课程色块 · 半透明无色）

课程块为**无色玻璃**：极淡暗底 + 顶部受光渐变，背后格子经 `backdrop-filter` 模糊折射；上下缘为受光镜面描边（mask 渐变边框），底部内阴影模拟玻璃厚度。课程识别色只保留在课程名的浅色文字上，色块本身不染色。

交互：桌面端鼠标移动有**跟随高光**；触屏端**按下即亮**（`.is-lit`），按住拖动可移动高光，抬起熄灭；悬停/点亮时玻璃上浮，按下轻微回缩。移动端自动降档：模糊半径 16px→10px、入场动画换轻量版本、课表网格收紧（时间轴 62px、min-width 660px）减少横向滚动量。

> 实现注意：带动画的元素统一用 `animation-fill-mode: backwards`——若用 `both/forwards`，动画结束后的 `transform` 会覆盖 `:hover` 位移（历史 bug，回归测试已覆盖）。

### 教务系统导入（三步向导动效）

「填写账号 → 读取中 → 预览勾选」每次换页都有统一的 step-in 过渡（上浮 + 缩放 + 去模糊）；读取中为呼吸辉光的液态光球 + 环绕卫星点 + 跳动省略号 + 步骤点脉冲；预览列表逐项错峰入场，冲突项置灰不可勾选。预览列表项同样为轻量玻璃材质。

性能与可访问性：粒子层在页面隐藏时暂停、随窗口防抖重建；系统设置「减弱动态效果」时全部动画与粒子自动关闭。

## 自检

**数据层自检**（零依赖，只需 Node.js）：

```bash
node demo/test/store.test.js
```

覆盖 53 项：节次时间、周次展开（单周 / 双周）、按周过滤、空周次、搜索、新增、字段校验、
时间冲突检测、更新、删除、教务系统导入（含冲突跳过与重复导入拦截）、清空与重置。
接入真实接口后，该脚本可作为数据层的契约测试继续使用。

**UI 冒烟测试**（需 jsdom，真实执行页面脚本）：

```bash
npm install jsdom        # 任选方式装好 jsdom
NODE_PATH=<jsdom 所在 node_modules> node demo/test/ui.smoke.js
```

覆盖 77 项：首屏渲染、时间轴与角标、今天高亮、课程块信息完整度、周次切换、空态、搜索、详情、
新增（含冲突拦截）、删除、清空、重置，以及完整的教务系统导入流程（含读取中光球、步骤过渡）、
品牌移除、网格显式定位回归、PWA 基建（manifest / 图标 / SW / meta）。

## 已知边界

- 数据仅存于内存，刷新即重置（PWA 离线打开同样重置，不做本地持久化）
- 「从教务系统导入」为**模拟流程**（不连接真实系统），用于演示交互与冲突处理；
  真实抓取按 PLAN.md 的方案在阶段一/三实现
- 未实现登录、多学期切换、课表导出（ICS/HTML）等，属于后续接入真实教务系统后的范围
- 课表在窄屏下仍需横向滚动（已收紧时间轴与单元格宽度），未做移动端专属网格重排
- 动效在 `prefers-reduced-motion` 下自动关闭；粒子层需要支持 canvas 的浏览器
- PWA 安装需要 http(s) 环境；`file://` 双击打开只能查看，不能安装/离线
